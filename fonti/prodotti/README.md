# Ricerca sui prodotti

Un file per strumento con quello che si sa del mercato: chi muove il prezzo e quando, eventi, legami con altri mercati, crolli, costi presso IG. È la parte dell'archivio con più dati e più rumore.

**Come consultarla**
- Si legge prima di scrivere le proposte, non per giustificarle dopo.
- Le informazioni sono divise per grado. Una proposta può nascere solo dal grado A, o da un'ipotesi del B con direzione dichiarata prima del test.
- Il grado C è contesto: non diventa codice.
- Le informazioni invecchiano (calendari, tassi, costi): ogni file indica la data della ricerca, e i dati vanno ricontrollati se sono passati più di 12 mesi.
- File presenti: `audjpy.md`, `dax.md`, `gbpjpy.md`, `nasdaq.md`, `oro.md`, `usdchf.md`.
- I legami con altri mercati non sono utilizzabili direttamente: ProOrder non può leggere un altro strumento dentro una strategia (forum ProRealCode, nessun annuncio contrario trovato).
