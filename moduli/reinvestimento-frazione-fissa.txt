// MODULO: reinvestimento a frazione fissa del capitale
// Validato su: 128 BIAS HOUR AUDJPY 1H (M6), backtest 2014-2026 in yen: crescita
//              composta regolare, accettato da Andrea il 2026-11-20.
// Richiede: PsL, PsS già calcolate con la taglia base del sistema (prima dei limiti
//           MaxPosition / minimo 1), StrategyProfit.
// Produce:  FattoreRein, CapitaleAttuale; moltiplica PsL e PsS.
//
// CapitaleValuta va espresso nella valuta di StrategyProfit, cioè quella dello
// strumento (yen sui cross in yen, dollari su EURUSD, euro sul DAX...), con il valore
// del capitale iniziale del backtest. Mai sommare StrategyProfit a un capitale in
// un'altra valuta: è l'errore che ha rotto M1.
// Su un sistema con taglia calcolata sullo stop, scegliere la frazione guardando la
// leva che ne risulta (valore della posizione / capitale): su 165 DAX il 5% di rischio
// con stop al 3% dava leva 1,7, meno del contratto minimo, e reinvestiva troppo poco.

CapitaleValuta    = 800000   // capitale nella valuta dello strumento
QuotaReinvestita  = 1        // 1 = taglia proporzionale al capitale; 0.5 = metà dei profitti
FattoreMinimo     = 0.5
FattoreMassimo    = 25

CapitaleAttuale = CapitaleValuta + StrategyProfit
FattoreRein = 1 + QuotaReinvestita * StrategyProfit / CapitaleValuta
FattoreRein = max(FattoreMinimo, min(FattoreMassimo, FattoreRein))

PsL = PsL * FattoreRein
PsS = PsS * FattoreRein
