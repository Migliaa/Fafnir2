//-------------------------------------------------------------------------
// USDCHF 1H  |  M2, tentativo 2: FRANCO RIFUGIO A ONDATE (sistema nuovo)
// Grafico: USD/CHF Mini (10.000 USD, 1 franco per pip), 1 ORA, orari italiani.
// Tutti i valori in franchi, la valuta di StrategyProfit.
//
// L'idea. Il franco si apprezza sul dollaro quando le borse scendono e la volatilità
// sale, su orizzonti da poche ore a più giorni, e di più nei periodi agitati
// (Ranaldo-Söderlind 2010; fonti/prodotti/usdchf.md, A1). Dentro USD/CHF non si legge
// la borsa, ma un forte calo del cambio in giornata è il segno di un'ondata di domanda
// di rifugio. Sull'oro e sul Nasdaq di Andrea i movimenti forti della giornata
// proseguono per giorni (idee, V6, P4, S7): qui si prova la stessa struttura sul
// franco. Invece di un giorno fisso della settimana, lo short entra quando c'è il
// movimento.
// Regola: tra le 09:00 e le 21:00, da lunedì a giovedì, se USD/CHF è sceso
// dall'apertura del giorno di almeno SogliaS escursioni orarie medie (200 ore) e la
// barra chiude sotto il minimo delle 24 ore precedenti, short al mercato. Stop a
// KStop escursioni giornaliere medie, rischio fisso in franchi, uscita dopo
// DurataBarre barre o il venerdì alle 21:00 (niente fine settimana), nessun target.
// Un solo ingresso al giorno.
// Rischio opposto: la BNS interviene contro gli apprezzamenti rapidi del franco, e
// alcune ondate si fermano di colpo. Il 15 e 16 gennaio 2015 sono esclusi: dopo
// l'abbandono del cambio minimo nessuno short sarebbe stato eseguito ai prezzi del
// backtest.
// Il long simmetrico (forte salita, nuovo massimo) è la prova di controllo: se rende
// quanto lo short, il vantaggio è momento generico e non domanda di rifugio.
//
// RIFERIMENTO: è un sistema nuovo, senza interruttore che riproduca l'originale. Si
// confronta con il riferimento di M1 (M1 con UsaM1 = 0), che ha lo stesso rischio
// di 90 franchi a trade.
//
// COME PROVARLO
// a) Valori del file, report short.
// b) EntraLong = 1, report long: attesa più debole dello short.
// c) Ottimizzazione dello short (280 combinazioni):
//      SogliaS     da 2.5 a 6 passo 0.5
//      KStop       da 1 a 2.5 passo 0.5
//      DurataBarre da 24 a 72 passo 12   (barre da 1 ora, 1-3 giorni)
//    fino al 31/12/2021, verifica sul 2022-2026, centro di una zona stabile.
//
// COME GIUDICARLO
// - Profit factor sopra 1,3 e guadagno medio sopra i 6 franchi a trade per contratto
//   (spread più un paio di notti di finanziamento, che il backtest non vede).
// - Guadagno medio in rapporto al rischio di 90 franchi, profitto / drawdown, anni in
//   perdita; confronto con il riferimento di M1 a parità di rischio.
// - Se le perdite cadono in mesi diversi da quelle del ciclo di fine settimana, i due
//   si possono tenere nello stesso sistema.
//
// Le righe GRAPH in fondo servono solo nel backtest: toglile prima del reale.
//-------------------------------------------------------------------------
DEFPARAM CumulateOrders = False
DEFPARAM PreLoadBars = 1000

//=========================================================================
// CONSOLE DI GESTIONE  -  tutto in franchi, la valuta di StrategyProfit su USD/CHF
//
// 1. SOLDI SUL CONTO DESTINATI AL SISTEMA (in franchi)
//    Primo avvio: CapitaleVersato = soldi messi nel sistema, ProfittiPrecedenti = 0.
//    Riavvio: ProfittiPrecedenti = quanto il sistema ha già guadagnato (o perso, col
//    meno) nelle esecuzioni precedenti, perché ProRealTime riparte da zero.
//    Prelievo o versamento: cambia CapitaleVersato, non i profitti.
//    Backtest: CapitaleVersato = capitale del backtest, ProfittiPrecedenti = 0.
CapitaleVersato     = 6000     // PER IL TEST
ProfittiPrecedenti  = 0

// 2. RISCHIO PER TRADE: % del capitale che si perde se scatta lo stop
RischioLong         = 1.5      // PER IL TEST: 90 franchi, come M1
RischioShort        = 1.5

// 3. MANOPOLA DEL REINVESTIMENTO: 0 = rischio fisso, 1 = normale, 2 = profitti doppi
Aggressivita        = 0        // PER IL TEST

// 4. LIMITI DELLA POSIZIONE
MinContratti        = 0.5      // verificare il minimo di IG sul mini
MaxContratti        = 80
ValorePerPunto      = 10000    // franchi per 1,00 di prezzo, 1 contratto mini (10.000 USD)
//=========================================================================

// --- Interruttori
EntraShort = 1
EntraLong  = 0                 // b) 1 = stessa regola al rialzo

// --- Variabili da ottimizzare
SogliaS     = 3.5              // calo dall'apertura in escursioni orarie medie; da 2.5 a 6 passo 0.5
KStop       = 1.5              // stop in escursioni giornaliere medie; da 1 a 2.5 passo 0.5
DurataBarre = 48               // uscita a tempo; da 24 a 72 passo 12

// --- Parametri fissi
SogliaL     = SogliaS          // il long usa la stessa soglia
OraMin      = 9
OraMax      = 21
BarreMinMax = 24               // nuovo minimo (o massimo) delle 24 ore precedenti
OraVenerdi  = 21               // chiusura di tutto il venerdì

// --- Escursioni medie
AtrH = AverageTrueRange[200](close)
TIMEFRAME(daily, updateonclose)
AtrD = AverageTrueRange[20](close)
TIMEFRAME(default)

Dist = KStop * AtrD

// --- Posizioni (dalla console)
CapitaleAttuale = CapitaleVersato + ProfittiPrecedenti + StrategyProfit
Profitti = ProfittiPrecedenti + StrategyProfit
IF Profitti > 0 THEN
   CapitaleBase = CapitaleVersato + Aggressivita * Profitti
ELSE
   CapitaleBase = CapitaleVersato + Profitti
ENDIF
RischioCHFL = max(0, CapitaleBase) * RischioLong / 100
RischioCHFS = max(0, CapitaleBase) * RischioShort / 100
PsL = max(MinContratti, min(MaxContratti, RischioCHFL / (Dist * ValorePerPunto)))
PsS = max(MinContratti, min(MaxContratti, RischioCHFS / (Dist * ValorePerPunto)))

// --- Condizioni
GiornoOK = DayOfWeek >= 1 AND DayOfWeek <= 4
OraOK = Hour >= OraMin AND Hour <= OraMax
Escluso = (Year = 2015 AND Month = 1 AND (Day = 15 OR Day = 16))

CaloForte    = Dopen(0) - close >= SogliaS * AtrH AND close < lowest[BarreMinMax](low[1])
SalitaForte  = close - Dopen(0) >= SogliaL * AtrH AND close > highest[BarreMinMax](high[1])

ONCE UltimoGiorno = 0
PuoEntrare = GiornoOK AND OraOK AND NOT Escluso AND NOT OnMarket AND Date <> UltimoGiorno AND AtrH > 0 AND AtrD > 0

// --- Ingressi
IF PuoEntrare AND EntraShort = 1 AND CaloForte THEN
   SELLSHORT PsS LOTS AT MARKET
   SET STOP LOSS Dist
   SET TARGET %PROFIT 50       // nessun target
   UltimoGiorno = Date
ELSIF PuoEntrare AND EntraLong = 1 AND SalitaForte THEN
   BUY PsL LOTS AT MARKET
   SET STOP LOSS Dist
   SET TARGET %PROFIT 50
   UltimoGiorno = Date
ENDIF

// --- Uscite: a tempo, il venerdì sera, mai nel fine settimana
FineSettimana = (DayOfWeek = 5 AND Hour >= OraVenerdi) OR DayOfWeek = 6 OR DayOfWeek = 0
Scaduto = barindex - tradeindex >= DurataBarre

IF ShortOnMarket AND (Scaduto OR FineSettimana) THEN
   EXITSHORT AT MARKET
ENDIF
IF LongOnMarket AND (Scaduto OR FineSettimana) THEN
   SELL AT MARKET
ENDIF

// --- Controlli (solo backtest)
GRAPH PsS AS "contratti"
GRAPH (Dopen(0) - close) / AtrH AS "calo dall'apertura in escursioni orarie"
